# AI Market Radar — Android

نسخه اولیه اپ اندروید پروژه AI Market Radar.

## امکانات رابط کاربری
- داشبورد فارسی
- BTC / ETH
- دلار آزاد
- طلای ۱۸ عیار
- نقره
- اخبار و تحلیل AI
- Whale Alert
- اعلان‌ها
- تنظیمات Telegram

## نکته مهم
این پروژه عمداً کلیدهای API و Telegram Bot Token را داخل APK قرار نمی‌دهد.
برای داده زنده، اپ باید به Backend پروژه AI Market Radar وصل شود.

ساختار پیشنهادی:
Android App -> Backend/API -> News + AI + Whale Alert + Free Market FX -> Telegram

## ساخت APK
در Android Studio پروژه را باز کنید و:
Build > Build APK(s)

حداقل Android: 8.0 (API 26)
